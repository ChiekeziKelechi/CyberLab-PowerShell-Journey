# CyberLab PowerShell Journey

This repository contains my practical work while learning Ubuntu Server, PowerShell, Git, and GitHub.

In this project, I learned how to:

* Create an Ubuntu Server virtual machine using VirtualBox.
* Use basic Linux commands such as `pwd`, `ls`, `cd`, and `mkdir`.
* Create files and directories.
* Use Git to track changes.
* Upload a project to GitHub.

The screenshots in this repository show the steps I completed during the project.

This project was completed as part of my Linux and Git learning journey.
